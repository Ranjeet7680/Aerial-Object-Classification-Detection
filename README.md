🚀 Aerial Object Classification & Detection

Aerial Object Classification & Detection is a deep learning-based computer vision project designed to identify and distinguish aerial objects—specifically birds and drones—from images and videos. The system integrates both image classification and object detection techniques to provide accurate recognition and localization of objects in real-world aerial environments.

🔍 Project Overview

This project implements a dual-model approach:

Image Classification: Classifies input images into categories such as bird or drone using deep learning models like CNN/MobileNet.
Object Detection: Uses advanced detection algorithms such as YOLO (e.g., YOLOv8) to locate objects in images with bounding boxes.

The combination of these techniques ensures both high accuracy and real-time performance, making it suitable for surveillance, defense, and drone monitoring systems.
